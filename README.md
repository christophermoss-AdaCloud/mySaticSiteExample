# Unit 12: SHUMP - Shoot 'Em Up Game

This repository contains two implementations of the SHUMP (Shoot 'Em Up) game for Unit 12:

## 1. HTML/JavaScript Version (Web-based)

A browser-based version that runs on GitHub Pages.

**Files:**
- `index.html` - Main game page
- `styles.css` - Styling
- `game.js` - Game logic

**How to play:**
- Visit the GitHub Pages site (once deployed)
- Or open `index.html` in a web browser

**Controls:**
- Arrow Keys: Move ship
- Space: Shoot
- ESC: Pause

## 2. Python/Pygame Version (Desktop)

A desktop version implemented with Python and Pygame.

**Location:** `pygame-version/`

**How to run:**
```bash
cd pygame-version
pip install -r requirements.txt
python shump_game.py
```

See `pygame-version/README.md` for detailed instructions.

**Controls:**
- Arrow Keys: Move ship
- Space: Shoot
- ESC: Pause
- R: Restart (when game over)

## Game Features

Both versions include:
- Player ship with movement controls
- Shooting mechanics
- Enemy waves
- Collision detection
- Score tracking
- Lives system
- Game over state

Choose the version that best fits your needs!
