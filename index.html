Part 1: Flowchart Basics

What is a Flowchart?

A flowchart is a visual diagram that represents the sequence of steps and decisions needed to perform a process. In programming, flowcharts help us plan our code before we write it, making it easier to understand and debug.

Why Use Flowcharts?

  • Planning: Helps you think through the logic before coding
  • Communication: Easy way to explain your program to others
  • Documentation: Creates a visual record of how your program works
  • Debugging: Helps identify logical errors in your program

Standard Flowchart Symbols

Flowcharts use standard symbols that have specific meanings:

Start/End

Oval (Terminator)

Marks the beginning or end of a program or process.

Example: Start, End, Stop
Process

Rectangle (Process)

Represents a process, action, or operation.

Example: Calculate total, Set x = 5
Decision

Diamond (Decision)

Represents a decision or conditional statement.

Example: Is x > 10?, Is user logged in?
Input/Output

Parallelogram (Input/Output)

Represents data input or output operations.

Example: Input name, Print result
→

Arrow (Flow Line)

Shows the direction and sequence of steps.

Connects symbols to show flow
A

Circle (Connector)

Connects different parts of a flowchart.

Used when flowchart spans multiple pages

Basic Flowchart Rules

  1. Every flowchart must have a Start and End symbol
  2. Arrows should flow from top to bottom and left to right when possible
  3. Decision symbols should have exactly two exit paths: Yes and No
  4. All symbols should be connected with arrows (no floating symbols)
  5. Keep your flowchart neat and easy to follow

Part 2: Python Flowcharts

Mapping Flowcharts to Python Code

Understanding how flowchart elements translate to Python code is essential for effective programming:

Flowchart Element Python Equivalent Example
Start/End Beginning/End of program or function def main(): / return
Process Assignment or calculation total = price * quantity
Decision if/elif/else statements if age >= 18:
Input input() function name = input("Enter name: ")
Output print() function print("Hello, " + name)
Loop (back arrow) while or for loop while count < 10:

Example 1: Simple Input/Output Program

Flowchart Steps:

  1. Start
  2. Input: Get user's name
  3. Output: Display greeting
  4. End

Python Code:

# Simple greeting program
name = input("What is your name? ")
print("Hello, " + name + "! Welcome to Python!")

Example 2: Decision Making (if/else)

Flowchart Steps:

  1. Start
  2. Input: Get user's age
  3. Decision: Is age >= 18?
  4. Yes → Output: "You can vote"
  5. No → Output: "Too young to vote"
  6. End

Python Code:

# Voting eligibility checker
age = int(input("Enter your age: "))

if age >= 18:
    print("You are eligible to vote!")
else:
    print("You are too young to vote.")
    years_left = 18 - age
    print(f"You can vote in {years_left} years.")

Example 3: Loops (Repetition)

Flowchart Steps:

  1. Start
  2. Process: Set counter = 1
  3. Decision: Is counter <= 5?
  4. Yes → Output: Display counter
  5. Process: Add 1 to counter
  6. Arrow loops back to step 3
  7. No → Output: "Finished counting"
  8. End

Python Code:

# Counting program using while loop
counter = 1

while counter <= 5:
    print(f"Count: {counter}")
    counter = counter + 1

print("Finished counting!")

# Alternative using for loop
for i in range(1, 6):
    print(f"Count: {i}")
print("Finished counting!")

Example 4: Combining Decisions and Loops

Program: Number Guessing Game

  1. Start
  2. Process: Set secret_number = 7
  3. Input: Get user's guess
  4. Decision: Is guess == secret_number?
  5. No → Output: "Try again"
  6. Arrow loops back to step 3
  7. Yes → Output: "Correct!"
  8. End

Python Code:

# Number guessing game
secret_number = 7
guess = 0

while guess != secret_number:
    guess = int(input("Guess the number (1-10): "))
    
    if guess < secret_number:
        print("Too low! Try again.")
    elif guess > secret_number:
        print("Too high! Try again.")
    else:
        print("Correct! Well done!")

print("Game Over")

Best Practices for Python Flowcharts

1. Start Simple

Begin with the main steps, then add details. Don't try to include everything at once.

2. Use Consistent Symbols

Always use the correct symbol for each type of action to maintain clarity.

3. Keep It Readable

Use clear, concise text inside symbols. Avoid lengthy descriptions.

4. Test Your Logic

Trace through your flowchart with sample data before writing code.

5. Match Your Code

Update your flowchart if you change your code, and vice versa.

Lesson Summary

Key Points to Remember

Flowcharts Are Visual Plans

They help you plan, communicate, and debug your programs before and after coding.

Standard Symbols

Oval = Start/End, Rectangle = Process, Diamond = Decision, Parallelogram = Input/Output

Python Mapping

Decisions become if/else statements, loops use back-arrows, processes are assignments.

Practice Makes Perfect

The more flowcharts you create and convert to code, the better programmer you'll become.
