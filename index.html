Unit 12: SHUMP

A Shoot 'Em Up Game

About the Game

Welcome to SHUMP, an exciting shoot 'em up game developed as part of Unit 12. Experience fast-paced action as you navigate through waves of enemies and dodge incoming fire!

Note: This is the web-based HTML/JavaScript version. A Python/Pygame desktop version is also available in the pygame-version directory.

Game Area

Score: 0

Lives: 3

How to Play

  • Arrow Keys: Move your ship
  • Space Bar: Shoot
  • ESC: Pause game

Objective

Destroy enemy ships, avoid their fire, and survive as long as possible to achieve the highest score!

Features

🚀 Fast-Paced Action

Experience thrilling gameplay with increasing difficulty

🎯 Score System

Compete for high scores and track your progress

👾 Enemy Waves

Face challenging enemy patterns and behaviors

💥 Smooth Controls

Responsive keyboard controls for precise movement
