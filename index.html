16. Flowcharts (Part 1)

Today's Focus

Today we are going to look at how flowcharts are used in game development

What is a Flowchart?

A diagram that uses graphic symbols to depict the nature and flow of the steps in a process.

Benefits of Using Flowcharts

Promote Process Understanding

Visualize the logic of your program clearly

Provide Outline for Steps

Create a blueprint for your program

Identify Problem Areas

Spot improvement opportunities early

Depict Whole Project

Show the complete program graphically

Standard Flowchart Symbols

Flowcharts use standard symbols that have specific meanings:

Start/End

Oval (Terminator)

Marks the beginning or end of a program or process.

Process

Rectangle (Process)

Represents a process, action, or operation.

Decision

Diamond (Decision)

Represents a decision or conditional statement.

Input/Output

Parallelogram (Input/Output)

Represents data input or output operations.

→

Arrow (Flow Line)

Shows the direction and sequence of steps.

Flowchart Example: Rock, Paper, Scissors

Basic Flowchart Structure for Rock, Paper, Scissors

  1. Start (Oval)
  2. Player 1 Input (Parallelogram)
  3. Player 2 Input (Parallelogram)
  4. Decision: Does Player 1 win? (Diamond)
    • Yes → Display "Player 1 Wins!" (Parallelogram) → End (Oval)
    • No → Decision: Does Player 2 win? (Diamond)
      • Yes → Display "Player 2 Wins!" (Parallelogram) → End (Oval)
      • No → Display "Draw!" (Parallelogram) → End (Oval)
